# French pronunciation library

Static PWA release: 10,000 French word forms with source-backed IPA and conservative pronunciation-rule explanations.

This repository contains only the public website. Serve from GitHub Pages using the main branch root. No backend, package installation or build step is required.

Data attribution and licensing: [DATA-LICENSE.md](DATA-LICENSE.md) and [sources.html](sources.html).

To update, regenerate this folder from the maintained project, then commit and push the changes with GitHub Desktop. Keep the repository's .git directory. The site's service worker handles subsequent offline updates.
