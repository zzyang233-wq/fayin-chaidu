规则内容与疑难核验

人工维护的规则资料

Quick Rule 与 Detailed Rule 是基于可靠资料重新组织的中文短说明，不由查询时的模型自由生成。每条详细规则底部保留逐条 source refs。

  • Jean-Michel Kalmbach，《Guide de prononciation française》：规则结构、音位与拼写对应。
  • Éduscol：基础、高频且值得初学者优先学习的对应。
  • TV5MONDE Apprendre le français：面向 FLE 初学者的表达参考。
  • Académie française、CNRTL / TLFi：有争议或词汇性例外的核验。

简短中文释义

中文维基词典 / Wiktextract

释义来自中文维基词典，经 Kaikki 的原始 Wiktextract 数据提取。应用仅在法语词元与词性能够严格对应、释义足够短且没有明显多义冲突时显示；屈折词形可继承对应词元。没有可靠匹配就留空，不自动猜译。

可选真人录音

Wikimedia Commons / Lingua Libre

音频不是统一许可的数据包。每个文件分别保存文件页、speaker、许可、目标读音和审核结果。正式录音只来自用户试听认可的 A/B speaker pool，并继续要求严格转写、按相同拼写和 IPA 显式绑定具体 pronunciation、许可在白名单且元数据完整。真正多 IPA 歧义的录音不发布；代表录音审核不等同于逐文件声学听审。缺失音频时不会用 TTS 替代。

版本兼容与保守发布

Lexique-Infra 基于 Lexique 3.83，而整词主来源是 Lexique 4.00。版本缺失、不一致、重组冲突或对齐歧义不会静默修补：IPA 仍可在全词来源可靠时显示，但 segmentation 与 rule links 会被隐藏。正字法查询保留重音，只接受词库明确记录的 œ ↔ oe alias。

从 Lexique 与 Lexique-Infra 派生并随 V1 发布的词条、IPA 和对齐数据按 CC BY-SA 4.0 管理。应用代码与数据包是两个许可层；仓库当前尚未为软件代码另行声明许可，公开再分发代码前需完成许可选择与复核。本说明是工程记录，不构成法律意见。
